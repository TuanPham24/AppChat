# Real-time Chat Application

A full-stack real-time chat application that enables users to connect, manage friendships, and communicate through direct and group conversations.

## Live Demo

[Open the application](https://wypte-app-chat-frontend.vercel.app/)

## Key Features

* Real-time direct and group messaging
* Online/offline presence updates
* Friend requests: send, accept, and reject
* Contact management and direct conversations
* JWT-based authentication and protected routes
* Responsive user interface
